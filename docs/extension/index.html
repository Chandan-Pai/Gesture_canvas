Chrome extension

Laser pointer and ink overlay for shared tabs in Google Meet, Zoom, and Teams.

Features

  • Tab mode (recommended) — overlay on a shared Slides/Meet tab; camera in side panel
  • Screen pointer — fullscreen overlay; share entire screen in Meet
  • Pointer / Write / Off — laser, pen, arrow, box, erase, slide navigation
  • Collaboration — multiple companions per session (unique laser colors)

Install

  1. Clone the repo
  2. Chrome → chrome://extensions → enable Developer mode
  3. Load unpacked → select the extension/ folder
  4. After updates, click Reload on the extension card

Google Slides + Meet (tab mode)

  1. Open Google Slides → Present → Present in this tab
  2. Extension popup → Start on this tab (side panel opens)
  3. Allow camera in the grant tab; keep the side panel open
  4. In Meet → Present this tab
  5. Pointer: index finger = red laser
  6. 🤟 Three fingers: toggle Write mode (draw / erase)
  7. 👍 / 👎: next / previous slide (hold, then release)

Camera permission

Camera runs on the extension origin, not docs.google.com. Use the grant tab when prompted — allowing camera on Slides alone does not enable gestures.

Webinar mode (entire screen)

  1. Extension popup → Start screen pointer
  2. Open gesture controller with session ID from popup
  3. In Meet → Present now → Entire screen
  4. Point with index finger — laser appears over the shared screen

Local dev (optional relay)

npm install
npm run dev

Open https://localhost:3000 once and accept the certificate. Companion URL: https://localhost:3000/companion/?session=YOUR_ID

Troubleshooting

IssueFix
Pointer not in MeetShare this tab or entire screen (not a window only)
Slides won’t advanceUse Present in this tab, not edit mode
No gesturesKeep side panel open; reload extension + refresh Slides tab
Camera blockedUse the grant tab; check Chrome site settings for the extension
