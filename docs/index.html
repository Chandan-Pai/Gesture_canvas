Gesture Canvas

Hand-gesture laser pointer and annotations for webinars and screen sharing.

Open Gesture Controller

Try it (host)

  1. Clone the repo and load the Chrome extension from extension/
  2. Run npm run dev for the local WebSocket relay
  3. Click Start screen pointer in the extension popup
  4. In Meet: share Entire screen
  5. Open the gesture controller and enter the session ID from the popup

Collaborate (guest)

Host shares the companion link with session ID (and relay URL if not using localhost). Each guest opens the controller on phone or laptop — unique laser colors per participant.

Hosted relay (Phase 3)

Deploy relay/standalone-relay.mjs, then set GC_PUBLIC_WS in extension/lib/gc-config.js and docs/lib/gc-config.js.
