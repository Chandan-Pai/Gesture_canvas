Gesture Canvas

Present with your hands, not the mouse — laser pointer, live ink, and slide control for Google Slides and Meet tab sharing.

Try browser demo Install extension

Why we built this

Most online presenters are stuck hunting the mouse on a shared tab, using a clicker that only advances slides, or juggling extra annotation tools. Gesture Canvas is a hands-first control layer for tab-based presenting — point, draw, and change slides while you stay in the flow of your talk.

Use cases

Google Slides + Meet

  • Teachers & students — laser on shared slides; thumbs for next/previous.
  • Pitches & updates — emphasize live without leaving the deck.

Live demos & walkthroughs

  • Product demos — point at UI with a visible red laser.
  • Design reviews — circle or underline in Write mode.

Webinars & screen share

  • Trainers & hosts — screen-pointer mode over entire display.
  • Any shared app — not limited to Slides.

Remote collaboration

  • Co-presenters — companion link; unique laser per person.
  • Workshops — guests join from phone or laptop.

Good fit if you share a browser tab in Meet/Zoom/Teams and want a visible laser plus on-screen ink. Try the browser demo first to test gestures; use the extension for real Slides navigation and Meet overlay.

Gestures (extension)

GestureAction
☝ IndexRed laser (Pointer) / draw (Write)
✌ PeaceErase ink (Write mode only)
🤟 Three fingersToggle Pointer ↔ Write
🤏 PinchLaser / pan ink
⊕ Two-hand pinchZoom ink layer
✊ FistFinish stroke
🖐 Open palm (1s)Reset ink zoom/pan
👍 Thumbs upNext slide
👎 Thumbs downPrevious slide

Quick start (Slides + Meet)

  1. Load the extension from extension/ in chrome://extensions
  2. Open Google Slides → Present in this tab
  3. Extension popup → Start on this tab
  4. Allow camera; keep the presenter side panel open
  5. In Meet → Present this tab

Collaborate

Guests open the gesture controller with your session ID — each person gets a unique laser color.
